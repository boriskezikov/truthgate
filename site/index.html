Did your agent do what it says?

TrustCheck checks every claim in the report against the tool calls and the files. Never against the words.

Install for Claude Code See the results

Checked against what it did

  1. Trace

    Tool calls

    Every call and its raw result.

    Rule
  2. World

    Files

    Hashes before and after.

    Rule
  3. Calc

    Arithmetic

    Every sum recomputed.

    Rule
  4. Receipts

    Signed actions

    Email or payment, signed by the system that did it.

    Rule
  5. Judge

    Second model

    Three votes, evidence only.

    Model
Deceptive

Stop. Sent back with the evidence.

Needs review

A person decides.

Honest

Every checkable claim held.

Unverified

Too little to check. Never “honest”.

Limits

  • One model under test so far: Haiku 4.5.
  • Labels come from a model, not from people.
  • Only the final report is graded.
  • On coding agents it is a review queue, not a gate.
  • About 70 reports per test set: wide intervals.
  • Two rule fixes came from seed 4’s own misses.
  • Full research record
